# Maps

This directory is intentionally empty in the template, because a `.vmap` is the
one artifact you cannot generate from a script.

To create one:

1. On Windows, launch the tools: `bun run launch`.
2. In the Asset Browser, choose **Hammer** → **File → New**.
3. Save it as `pudge_wars.vmap` in this directory. The name has to match the
   `maps` entry in `game/addoninfo.txt`.
4. Paint some ground, add a `light_environment` and an `info_player_start_*`
   for each stock team, then **File → Build** to cook it.

Compiled maps (`.vmap_c`, `.vpk`) are gitignored: they are large, binary, and
regenerated by the build. Every machine that needs to run the game has to cook
the map itself.

## What Pudge Wars expects of the map

The script does not read map geometry, but it assumes a shape. To match the
code (`src/vscripts/config.ts`), the `pudge_wars.vmap` should be:

- **Two-sided, split on the X axis.** Radiant spawns near `x = -3000`, Dire near
  `x = +3000`, each team's players spread along Y (`SPAWN_SPACING = 500`).
  Heroes are teleported onto these lines every spawn (`systems/spawnPositions.ts`),
  so exact Hammer spawn points are not required — but the playable ground has to
  cover them.
- **A river down the middle.** The river BUFF is a coordinate band, `x` in
  `[-400, 400]` (`RIVER_BAND`). Paint the water there so what players see matches
  where the buff actually applies. Widen the band in `config.ts` if you paint it
  wider.
- **Lit and flat enough to hook across.** Add a `light_environment`; Meat Hook
  and the drag travel in straight lines, so keep the mid-map open.

None of these are enforced by the engine — they are the contract between the
map you paint and the numbers in `config.ts`. Change one, change the other.
